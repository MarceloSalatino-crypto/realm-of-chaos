# Realm of Chaos - Fase 1

Projeto base pronto para Godot 4.

## O que já tem
- Cena principal World
- Player com CharacterBody2D
- AnimatedSprite2D com animações idle e walk
- CollisionShape2D
- Camera2D com suavização
- Background grande
- Decoração simples
- Script de movimento organizado

## Controles
- WASD ou setas: mover

## Como abrir
1. Extraia este ZIP em uma pasta nova.
2. Abra o Godot 4.
3. Clique em Importar.
4. Selecione o arquivo project.godot.
5. Aperte F5.
