# Assets originais gerados

Estes três assets foram criados especificamente para **Realm of Chaos** com o gerador de imagens integrado do Codex e depois processados/localizados no projeto.

- `hero_chaos_warden.png`: Guardião do Caos em pixel art, fundo chroma removido para alfa.
- `enemy_atlas.png`: atlas 3×2 com seis arquétipos; fundo chroma removido para alfa.
- `corrupted_forest_ground.png`: terreno ortográfico de floresta corrompida usado com repetição na arena.

Direção visual dos prompts: pixel art 16-bit de fantasia sombria, paleta limitada, silhuetas legíveis em escala de gameplay, sem texto, marcas ou elementos de terceiros. O atlas pediu, em ordem: espreitador ósseo, morcego rubro, cultista glacial, brutamonte de pedra, crânio de brasa e arauto do vazio.

Os PNGs transparentes foram validados com canal alfa e cantos totalmente transparentes. O terreno é opaco por design.
